# دفتر خدمات سلامت ۴۷۷ — وب‌سایت و سامانه درخواست آنلاین

وب‌سایت فارسی، واکنش‌گرا و RTL برای «دفتر خدمات سلامت ۴۷۷» در قزوین، شامل:

- معرفی دفتر، چهار خدمت اصلی با صفحه اختصاصی، مراحل دریافت خدمات و سؤالات متداول
- **فرم ثبت درخواست چندمرحله‌ای** با فیلدهای اختصاصی هر خدمت، بارگذاری امن مدارک و رضایت آگاهانه
- **کد پیگیری یکتا** و صفحه پیگیری (کد + چهار رقم آخر تماس)
- **پنل مدیریت** با نقش‌ها، مدیریت درخواست‌ها، مدارک، محتوا، تنظیمات مرکزی، اعلان‌ها و سابقه رویدادها
- **اعلان‌ها** از طریق ایمیل تراکنشی (Resend یا SMTP) و تلگرام، با صف و ارسال مجدد
- سئوی فنی و محلی، داده‌های ساختاریافته، sitemap، robots و نقشه تعاملی با لینک مسیریابی

- فناوری: Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS v4 · Zod · SQLite (پیش‌فرض) یا PostgreSQL · nodemailer / Resend

## شروع سریع
```bash
npm ci
cp .env.example .env
npm run dev          # http://localhost:3000
```

## قبل از انتشار (موارد نیازمند تصمیم دفتر)
- **ایمیل رسمی دفتر** `Info@Khadamat447.IR` است و پیش‌فرض `ADMIN_NOTIFICATION_EMAIL` و `PUBLIC_CONTACT_EMAIL` است؛ با متغیرهای محیطی قابل تغییر است.
- **ساعات کاری** ۸ تا ۱۶ است؛ روزهای کاری هنوز تأیید نشده‌اند.
- **ساعات کاری** تعیین نشده؛ تا تکمیل، در سایت نمایش داده نمی‌شود.
- **مدت نگهداری اطلاعات** و متن نهایی **حریم خصوصی و قوانین** باید بررسی حقوقی شوند.
- **فهرست مدارک هر خدمت** راهنما است و باید توسط دفتر تأیید شود (در صفحه خدمت با برچسب نمایش داده می‌شود).
- **تصویر Hero** فعلاً تصویر تولیدشده با هوش مصنوعی است و باید با عکس واقعی دفتر جایگزین شود.
- **میزبان، دامنه و سرویس ایمیل** هنوز انتخاب نشده‌اند؛ گزینه‌ها و نکات در `docs/DEPLOY.md` آمده است.

## ساختار پوشه‌ها
```
src/app/(public)/   صفحات عمومی (خدمات، ثبت درخواست، پیگیری، مقالات، تماس، ...)
src/app/admin/      پنل مدیریت (+ _actions: Server Actions با کنترل مجوز)
src/app/api/qr/     کد QR واقعی موقعیت دفتر
src/lib/db/         لایه پایگاه داده، schema.sql و داده اولیه (seed)
src/lib/            منطق دامنه: درخواست‌ها، پیگیری، فایل‌ها، اعلان‌ها، احراز هویت، تنظیمات
tests/unit          آزمون‌های واحد
tests/e2e           آزمون سرتاسری با مرورگر
scripts/            ایجاد مدیر کل، پشتیبان پایگاه داده
docs/               مستندات
```

## مجوز و داده‌های شخصی
داده‌های درخواست‌ها، مدارک و پایگاه داده **هرگز** در Git ثبت نمی‌شوند (`.data/` در `.gitignore` است). تصاویر تولیدشده با هوش مصنوعی به‌عنوان جایگزین موقت قرار گرفته‌اند و باید با تصاویر واقعی جایگزین شوند.
