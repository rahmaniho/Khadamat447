# دفتر خدمات سلامت ۴۷۷ — وب‌سایت و سامانه آنلاین

وب‌سایت رسمی **دفتر خدمات سلامت ۴۷۷ قزوین** همراه با سامانه کامل ثبت و پیگیری درخواست و
**پیشخوان مدیریت**. کل سامانه بدون وابستگی به سرور اجرا می‌شود:

- سایت عمومی به‌صورت استاتیک ساخته می‌شود (آمادهٔ استقرار روی Vercel، GitHub Pages یا هر میزبان فایل ایستا)
- منطق دامنه (ثبت درخواست، وضعیت‌ها، اعلان‌ها، محتوا، کاربران، تنظیمات، سابقه رویدادها) در مرورگر اجرا می‌شود
- داده‌های نمایشی در `localStorage` ذخیره می‌شوند؛ قالب واقعی سایت و همه امکانات **فعال** و قابل بررسی است

## تجربه موبایل

چیدمان سایت از ۳۲۰px به بالا با صفحه موبایل هم‌گام است:

- پشتیبانی از ناحیه امن گوشی‌های ناچ‌دار (`viewport-fit=cover` و `env(safe-area-inset-*)`)؛
  نوار اقدام شناور، اعلان‌ها، پنجره‌ها و کشوها با نوار وضعیت و نشانگر خانه تداخل ندارند
- فونت ورودی‌های فرم در موبایل ۱۶px است تا iOS هنگام فوکوس، صفحه را زوم خودکار نکند
- اهداف لمسی ≥۴۴px و نوار اقدام شناور «ثبت/پیگیری» (در صفحه‌هایی که خودِ اقدام هست، پنهان می‌شود)
- منوی موبایل با قفل اسکرول پس‌زمینه، بستن با Escape و بستن خودکار هنگام چرخش/بزرگ‌شدن صفحه
- جدول‌ها و گام‌شمارها در عرض کم با scroll افقی جداگانه، بدون شکستن چیدمان صفحه

## سئو و جئو (SEO / GEO)

- **سئو:** عنوان و توضیح یکتا + canonical برای هر صفحه، Open Graph/Twitter Card،
  `sitemap.xml` خودکار (خدمات، مقالات، دسته‌های پرسش)، `robots.txt` با مسدودسازی
  مسیرهای خصوصی، و داده ساختاریافته JSON-LD: سازمان محلی (نشانی، مختصات، نقشه،
  ساعات کاری ماشین‌خوان، کاتالوگ خدمات، شبکه‌های اجتماعی)، وب‌سایت با SearchAction،
  Service، Article، FAQPage، BreadcrumbList و ItemList
- **جئو (موتورهای مولد):** فایل `/llms.txt` ساخته‌شده از منبع یکتای محتوای سایت
  (معرفی، خدمات، تماس، ساعات کاری، گزیده پرسش‌ها و پیوند صفحه‌های کلیدی) + اجازه
  صریح خزیدن برای ربات‌های AI (GPTBot، OAI-SearchBot، ClaudeBot، PerplexityBot،
  Google-Extended، Applebot-Extended و…) با همان حریم خصوصی مسیرها
- هر دو حالت استقرار (سروری و خروجی استاتیک با basePath) همه این موارد را یکسان تولید می‌کنند

## اجرای محلی

```bash
npm ci
npm run dev        # http://localhost:3000
```

> **توسعه از راه دور / محیط پیش‌نمایش:** سرور توسعه روی `0.0.0.0` و زیر دامنه‌هایی
> مانند `*.e2b.app`، `*.vercel.app` یا تونل‌های `*.ngrok-free.app` هم کار می‌کند؛
> فهرست این میزبان‌ها در `allowedDevOrigins` داخل `next.config.ts` است. Next.js
> بدون آن، درخواست cross-origin به دارایی‌های `/_next/*` را با پاسخ ۴۰۳ رد می‌کند
> و صفحه بدون CSS/JS بالا می‌آید. اگر دامنه دیگری دارید، به همان فهرست اضافه کنید.

دستورهای دیگر:

```bash
npm run typecheck      # بررسی نوع‌ها
npm test               # آزمون‌های واحد (۲۴ آزمون)
npm run build          # ساخت کامل (Next.js)
npm run build:static   # خروجی استاتیک در out/ (برای GitHub Pages)
```

## استقرار روی Vercel (پیشنهادی)

۱. مخزن را به Vercel وصل کنید (Import Project) یا از دکمهٔ زیر استفاده کنید:

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/rahmaniho/Khadamat447)

۲. هیچ متغیر محیطی لازم نیست. Framework: **Next.js** — Build: `npm run build` — Output: پیش‌فرض.
۳. پس از استقرار، آدرس `https://<project>.vercel.app` را باز کنید.

> اختیاری: برای نمایش دامنهٔ واقعی در `sitemap.xml` و `canonical`ها، متغیر
> `NEXT_PUBLIC_SITE_URL` را با دامنهٔ نهایی تنظیم کنید.

## استقرار روی GitHub Pages

```bash
bash scripts/build-static.sh   # خروجی در out/ با basePath=/Khadamat447
```
یا با فعال کردن Actions: پس از ادغام در شاخهٔ `main`، گردش‌کار
`.github/workflows/deploy-pages.yml` سایت را روی Pages منتشر می‌کند.
سایت روی `https://<user>.github.io/Khadamat447/` در دسترس خواهد بود.

```

│  ├─ ui/                   # کیت رابط: primitives · form · overlay

│  └─ admin/                # پوسته و بخش‌های پیشخوان + نمودارهای SVG
└─ lib/
   ├─ content/              # منبع یکتای محتوا (خدمات، پرسش‌ها، مقالات، اطلاعات دفتر)
   ├─ store/                # موتور دامنه سمت مرورگر (localStorage) + بذر داده نمایشی
   ├─ format.ts             # قالب‌بندی فارسی، تاریخ جلالی، نرمال‌سازی متن
   ├─ seo.ts · digits.ts · cn.ts
   └─ ...
```

## یادداشت فنی

- **Next.js 16** (App Router) · **React 19** · **TypeScript** · **Tailwind CSS v4** · بدون وابستگی سنگین دیگر
- همه آیکون‌ها SVG خطی و درون‌ساخت هستند؛ فونت **وزیرمتن** به‌صورت محلی بارگذاری می‌شود (بدون CDN)
- حالت روشن/تاریک، RTL کامل، `prefers-reduced-motion` و استایل چاپ در نظر گرفته شده است
- داده‌ها فقط در مرورگر بازدیدکننده ذخیره می‌شوند؛ هیچ اطلاعاتی به سرور ارسال نمی‌گردد
- ساختار محتوا در `src/lib/content` متمرکز است؛ تغییر متن‌ها بدون دست‌زدن به اجزای رابط انجام می‌شود
