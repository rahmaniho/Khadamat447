# امنیت و حریم خصوصی (خلاصه پیاده‌سازی)

| موضوع | پیاده‌سازی |
|---|---|
| HTTPS و HSTS | هدر `Strict-Transport-Security`؛ پایان HTTPS در reverse proxy |
| CSP و هدرهای امنیتی | `Content-Security-Policy`، `X-Frame-Options`، `nosniff`، `Referrer-Policy`، `Permissions-Policy` در `next.config.ts` |
| احراز هویت | رمز با scrypt؛ کوکی httpOnly با امضای HMAC؛ نشست در پایگاه داده قابل بستن؛ ۵ تلاش ناموفق در ۱۵ دقیقه قفل موقت |
| کنترل دسترسی | نقش‌ها و ماتریس مجوز؛ هر Server Action و Route Handler مجوز را بررسی می‌کند |
| CSRF | Server Actions داخلی Next.js (بررسی مبدأ)؛ خروج فقط با درخواست همان مبدأ |
| XSS | Markdown بدون HTML خام؛ همه ورودی‌ها escape یا اعتبارسنجی؛ لینک‌های javascript: رد می‌شوند |
| تزریق SQL | همه کوئری‌ها پارامتری هستند |
| اعتبارسنجی | Zod و قواعد اختصاصی سمت سرور؛ کلیدهای فیلد فقط از تعریف خدمت پذیرفته می‌شوند |
| فایل‌ها | محدودیت حجم و تعداد؛ بررسی پسوند **و** امضای بایت (magic bytes)؛ نام تصادفی؛ ذخیره خارج از `public`؛ دانلود فقط با مجوز، بدون کش، با `Content-Disposition: attachment` و ثبت دسترسی |
| محدودیت نرخ | ثبت درخواست: ۱۰ در ۱۰ دقیقه برای هر IP؛ پیگیری: ۲۰ در ۱۰ دقیقه؛ ورود: ۲۰ در ۱۵ دقیقه (حافظه فرایند) |
| ضد ربات | فیلد تله پنهان `website`؛ ثبت تکراری با `clientSubmissionId` |
| ضد ثبت تکراری | دوبار کلیک: دکمه غیرفعال و شناسه ارسال یکتا؛ پیام موفقیت فقط پس از ذخیره |
| پیگیری درخواست | کد پیگیری + چهار رقم آخر تماس؛ یادداشت‌های داخلی و اطلاعات شخصی نمایش داده نمی‌شوند |
| سابقه رویدادها | تغییر وضعیت، دانلود/جایگزینی/حذف مدرک، خروجی، ورود و کاربران (بدون اطلاعات شخصی) |
| حداقل‌گرایی | کد ملی و اطلاعات پزشکی درخواست نمی‌شود؛ شماره و ایمیل در لاگ‌ها ماسک می‌شوند؛ IP فقط به‌صورت هش ذخیره می‌شود |
| خروجی CSV | فقط مدیر کل؛ بدون نام، شماره، ایمیل و توضیحات |
| نشانگرهای ایندکس | `noindex` برای پنل مدیریت، پیگیری و جست‌وجو؛ robots.txt؛ صفحه تأیید درخواست noindex |

## کارهای باقی‌مانده امنیتی
- احراز هویت دومرحله‌ای (TOTP) برای مدیران — پیاده‌سازی نشده است.
- محدودیت نرخ در حافظه است؛ برای چند نمونه برنامه باید به Redis یا لایه proxy منتقل شود.
- حذف خودکار اطلاعات پس از مدت نگهداری — فعلاً دستی (بایگانی و حذف در پنل).
